관리자 비밀번호 처음 설정

아직 비밀번호가 없습니다. 비밀번호와 GitHub 토큰을 넣으면 비밀번호(복원 불가능한 해시)가 저장소에 저장되고, 다음부터는 비밀번호만으로 들어올 수 있습니다.

토큰 만드는 방법
  1. GitHub 로그인 → 우측 상단 프로필 → Settings → 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → junglegym-naesu 선택
  3. Permissions → Repository permissions → Contents: Read and write 만 켜기
  4. Generate 후 표시되는 토큰을 복사해 위 칸에 붙여넣기 (다시 볼 수 없으니 바로 붙여넣기)
